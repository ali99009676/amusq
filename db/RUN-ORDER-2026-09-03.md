# ما يُنفَّذ في Supabase بهذا الترتيب (كلها آمنة التكرار)

1. CODES.sql      — أكواد التفعيل (أعد تنفيذه: فيه تحديث admin_codes)
2. PAYOUT.sql     — عمولة الرافع (أعد تنفيذه: قادح العمولة صار يشمل manual)

4. ORDERS.sql     — طلبات الشراء + صندوق الوارد
5. PUSH.sql       — إشعارات المتصفح
6. EXAMYEAR.sql   — «جاء في اختبار سابق» + أرقام الثقة
