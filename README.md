الدليل خطوة بخطوة في `docs/DEPLOY.md`.

## التشغيل محليًا
```bash
npm install      # jsdom للفحوص فقط — لا مكتبة واحدة تصل المتصفح
npm run check    # بناء + 376 فحصًا
```
ثم افتح `index.html` بنقرة مزدوجة — يعمل بلا خادم وبلا إنترنت.

## القواعد الثابتة (مهارة amusq-rules)
1. **قاعدة القداسة**: نص السؤال والخيارات حرفًا بحرف — تُفرض في تعليمات الذكاء، وفي الخادم بعد الرد، وفي الفحوص.
2. **بلا مكتبة خارجية في المتصفح** — يفحصها الاختبار آليًا.
3. **لا يظهر للطالب سؤال لم يعتمده المشرف** — RLS تفرضها في قاعدة البيانات.
4. **المفاتيح السرية في الخادم فقط** — الفحص يمنع أي أثر لها في ملف المتصفح.
5. **لا تُسلَّم ميزة بلا فحوصها** تمرّ ١٠٠٪.
